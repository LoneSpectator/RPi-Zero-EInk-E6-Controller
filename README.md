# RPi-Zero-EInk-E6-Controller

一个 Python 墨水屏控制程序：FastAPI + Pillow + SQLite，原生 HTML/CSS/JavaScript 控制台，无前端构建步骤。面向[**微雪7.3寸E6全彩色电子墨水屏**](https://www.waveshare.net/shop/RPi-Zero2W-PhotoPainter.htm)产品，通过 ARM64 容器部署到目标树莓派。

- **概览**：最后成功下发画面、最近 5 条刷新记录和即将执行的排程。所有页面的顶部状态栏按顺序显示服务器时间、环形电量百分比、屏幕刷新状态和服务状态；电量仪表悬停显示电压、电流和充放电状态，充电时圆环转动，连接异常以红色标识。
- **图片**：上传 JPG/PNG（12 MiB、2000 万像素以内），完整等比显示（白色留边）或居中裁剪铺满；自动处理 EXIF 方向、透明背景和六色抖动。
- **文本**：段落与混合样式、12–120 px 字号、粗体、斜体、横向左对齐/居中/两端对齐、纵向居上/居中/居下、六种文字/背景颜色、五种限定字体；服务端排版预览，内容溢出明确报错。名称留空时，使用正文第一行非空白文本去除空白后的内容作为名称（最长 120 字符）。
- **内容库**：点击缩略图放大预览，点击空白处关闭。图片显示名称；文本显示名称和去除空白、换行后的正文，过长时省略，悬停或聚焦可查看全文。支持搜索、按类型筛选、重命名、重复显示和添加排程；左侧勾选后可批量删除，删除前需确认。预览不入库，保存或“确认并刷新”才入库，每次成功显示更新显示时间。
- **默认壁纸**：启动时没有可显示内容或已保存画面，会获取 Bing 今日壁纸，保存到内容库并自动刷新屏幕。
- **排程**：增删改查、启用/停用，指定日期的某一分钟或五字段 cron。SQLite 持久化，串行刷新，执行结果可查。
- **日志**：按日期时间、刷新内容、类型、状态紧凑展示完整刷新记录，支持每页 20 / 50 / 100 条和翻页；失败记录可展开查看原因。默认保留最近 7 天，顶部可修改保留天数并保存。

## 容器镜像

- **容器页面**：[GitHub Container Registry](https://github.com/LoneSpectator/RPi-Zero-EInk-E6-Controller/pkgs/container/rpi-zero-eink-e6-controller)

## 树莓派真机部署

目标环境为 **Pi Zero 2 W + 64 位 Raspberry Pi OS（arm64）**。直接拉取预构建的 `linux/arm64` 镜像，无需在设备上构建或编译依赖。首次拉取会下载驱动依赖和全部字体；amd64 和 32 位 armv7 不在发布范围内。

1. 按[微雪 Wiki](https://www.waveshare.net/wiki/RPi_Zero_PhotoPainter)连接设备，确认是 E6 六色版本。使用 `sudo raspi-config` 开启 **SPI** 和 **I²C**，按提示重启。
2. 确认宿主机有 `/dev/spidev0.0`、`/dev/gpiochip0` 和 `/dev/i2c-1`。先停止微雪测试程序、原有 cron/相框服务，确保没有其他程序占用这些引脚。
3. 在树莓派上安装 Docker Engine、Compose 插件和 Git，然后获取部署配置：

```bash
git clone https://github.com/LoneSpectator/RPi-Zero-EInk-E6-Controller.git
cd RPi-Zero-EInk-E6-Controller
cp .env.example .env
```

按需编辑 `.env`：`WEB_PASSWORD` 未设置或为空时关闭认证，可直接访问控制台和 API；设置非空密码后启用 Basic 登录。需要从局域网电脑访问时，设置 `BIND_ADDRESS=0.0.0.0`。默认镜像为 `ghcr.io/lonespectator/rpi-zero-eink-e6-controller:latest`，可修改 `IMAGE` 固定到已发布的版本标签或 `sha-<完整提交 SHA>`。

拉取镜像并启动真机服务：

```bash
docker compose pull
docker compose up -d
docker compose logs -f
```

浏览器访问树莓派的 **8000 端口**。未设置密码时直接进入控制台；设置密码后，使用 `.env` 中的用户和密码登录（默认用户 `admin`）。默认只绑定 `127.0.0.1`；设置 `BIND_ADDRESS=0.0.0.0` 后才允许局域网访问。跨不可信网络访问时，在前面部署 HTTPS 反向代理。

硬件配置映射三个设备，不需要 `privileged: true`。容器默认 root，用于打开已映射的设备和写入数据目录。若改为普通用户运行，需自行配置设备组权限和数据目录权限。GPIO 采用 `lgpio`，无需在容器中伪造树莓派型号探测信息。

| 接口 | 配置 |
| --- | --- |
| 屏幕 | SPI0 CE0：`/dev/spidev0.0`，4 MHz，mode 0，内核控制 CS |
| 复位 / DC / BUSY | BCM 17 / 25 / 24 |
| 屏幕供电 | **BCM 27**，与该产品官方配置一致 |
| 电池监测 | I²C-1，INA219 默认 **0x43**，可用 `INA219_ADDRESS` 覆盖 |
| RTC | 由宿主系统负责校时，程序读取宿主系统时钟；不修改 DS3231 |

驱动来自[微雪官方产品仓库](https://github.com/waveshareteam/RPi_Zero_PhotoPainter)，固定来源提交见 [NOTICE](app/vendor/NOTICE.md)，保留上游许可声明；GPIO 容器适配独立实现。BUSY 有超时保护，异常会释放硬件资源。

首次部署且没有可显示内容时，服务会自动获取 Bing 今日壁纸并刷新；也可上传自己的图片。请核对物理屏幕的方向、颜色和电池电压。**实体屏幕、INA219 电池监测和 arm64 真机运行尚未完成验证。** 电子纸刷新较慢，过程中闪烁属驱动刷新行为，不支持局部或视频刷新，请避免频繁刷新。

### 默认壁纸

服务启动时检查内容库文件、最后保存的画面及等待刷新的画面；已有可用的 800 × 480 图片时跳过初始化。没有可显示内容时，从 Bing 官方接口获取今日壁纸，居中裁剪为 800 × 480 的六色图，保存到内容库并加入串行刷新队列，无需手动点击。条目保留壁纸日期、来源地址及版权署名信息。

下载在后台执行，不影响进入控制台。网络失败时页面显示提示，每 30 秒重试；期间上传自己的内容会结束默认壁纸初始化。容器重启后已有可用内容便不会重复下载或刷新。可在 `.env` 中设置 `BING_DEFAULT_WALLPAPER=false` 关闭此功能。

### “屏幕实时状态”的含义

屏幕正在刷新或已有任务等待刷新时，图片、文本和内容库的手动刷新按钮均禁用，完成后自动恢复；预览和仅保存内容仍可使用。提交前会重新检查状态，后端以同一事务检查并入队，忙碌时返回 HTTP 409，避免重复点击、多个页面或排程同时触发导致额外手动刷新。连接异常、无法确认状态时也暂停手动刷新。排程继续按原有规则串行执行。

控制台空闲时每四秒、刷新期间每秒读取服务状态，显示“待确认 / 刷新中 / 待机 / 刷新失败”、刷新队列，以及**最后成功下发的像素图**。该硬件没有屏幕像素回读或摄像头，无法确认断电、拔线或外部程序改屏后的实际可见画面。刷新失败或中断会明确提示实际画面可能未知；不会将排队或失败任务当作刷新成功。

### 电池状态与低电提醒

INA219 读取电池电压及双向电流，按官方板的 0.01 Ω 分流电阻换算。PhotoPainter 实机原始电流为负时表示放电、为正时表示充电；`INA219_CURRENT_POLARITY` 默认 `-1`，在读取层统一转换为供电量模型使用的“正值放电、负值充电”，其他接线方向可设置为 `1`。网页悬停提示显示原始电流；充电时电量圆环转动，充电结束或放电时停止，充放电状态可在悬停提示中查看。零电流或读数不可用时不会显示充电动画。实体充电指示灯没有已接入的控制接口，程序不控制充电电路或充电灯。

百分比采用通用 **4.2 V 单节锂电的非线性电压曲线**，结合 32 次 ADC 采样平均和 30 秒电压平滑。程序会从有效的放电负载变化中学习电池及线路电阻，用电流补偿电压偏移；没有足够有效样本时不假定内阻。默认曲线不是原配电芯的实测容量曲线，百分比仍是估算，不能代替专用电量计。

满电、空电的电压校准值与充放电证据保存在 SQLite 中，重启后保留。读取电流方向发生变化或从旧版方向模型升级时，已有电池学习数据会自动重置并重新学习：

- **满电校准**：已观察到明显充电及高电压下电流逐步衰减，随后电流回到 ±10 mA，电压在 4.1–4.3 V 连续稳定三分钟、波动不超过 20 mV，更新满电电压。如果服务启动时已充满或漏采了电流衰减阶段，则要求上述高电压、微小电流状态连续稳定 **15 分钟**，恢复满电校准。明显充放电、遥测失败、超过 12 秒的采样中断或超过 20 mV 的电压波动会重新计时，停机时间不计入稳定时长。电量仪表悬停可查看校准确认剩余时间；确认后显示 100%，校准电压、时间及判定方式保存在 SQLite 中，重启后保留。单次高电压或零电流不能触发。
- **空电校准**：放电期间电池电压低于或等于 3.15 V 持续至少 30 秒，记录该段最低补偿电压；下一次开始充电时更新空电电压。短时压降或普通部分充放电不用于端点校准，电压恢复到 3.4 V 以上会清除低压证据。

INA219 不提供充电管理芯片的满电/保护断电信号，上述终点由电流、电压及持续观测识别；若断电前没有采到有效低电样本，会保留原校准值。温度、老化及电芯型号也会影响曲线，两个端点的校准不等于整条容量曲线的实测标定。

**低于 20% 时，实体墨水屏画面内侧绘制 5 像素宽的纯红边框**，预览采用同样的边框。已有成功画面时会自动加入一次串行刷新，电量持续恢复到 20% 及以上 30 秒后移除边框；不会在每次状态轮询时重复刷新。原始画面单独保留，移除边框可恢复原始像素，即使内容库条目已被删除也能保留当前画面。遥测不可用时不会清除已有低电提醒。

## 刷新日志

侧边栏“日志”位于“排程”之后，展示手动、定时、默认壁纸和电量提醒产生的刷新记录，按最新时间在前排序。已结束任务使用完成时间，等待中及刷新中的任务使用提交时间；日期与时间按服务器配置的时区显示。

日志默认保留最近 **7 天**。在页面顶部修改“最多保存”天数并保存后，设置写入 SQLite，重启仍保留；缩短保留期时立即清理超期记录。服务启动及运行期间也会自动清理。保留规则按完成时间计算，历史记录缺少完成时间时使用提交时间；等待中和刷新中的任务会保留至结束。清理日志后，最后成功画面仍保留。

## 文本与字体

编辑器默认显示“**五颜六色的黑**”：六个字依次使用红、黄、蓝、绿、白、黑，统一加粗；白色的“的”在默认白底上不可见，正文中仍保留该字。默认思源黑体、32 px、水平居中、纵向居上、白色背景和 24 px 边距，可直接修改或生成预览。

屏幕允许的颜色只有 `#000000`、`#ffffff`、`#ff0000`、`#ffff00`、`#0000ff`、`#00ff00`。服务端校验颜色、字体、字号、文档长度；粘贴按纯文本处理，通过工具栏添加样式。富文本传递为结构化段落及文字片段，不执行 HTML。六色量化后同一份 PNG 同时用于预览、保存和设备显示，物理色彩受光线及面板影响。

| 控制台字体 | 容器提供的字体 | 自定义字体路径变量 |
| --- | --- | --- |
| 黑体 | 文泉驿正黑（开源替代） | `FONT_HEITI` |
| 宋体 | AR PL UMing（开源替代） | `FONT_SONGTI` |
| 楷体 | AR PL UKai（开源替代） | `FONT_KAITI` |
| 思源黑体 | Noto Sans CJK SC（对应项目版本） | `FONT_SOURCE_SANS` |
| 思源宋体 | Noto Serif CJK SC（对应项目版本） | `FONT_SOURCE_SERIF` |

字形粗体和斜体由 Pillow 合成。编辑区使用浏览器字体，**生成后的像素预览是最终排版依据**。需要特定厂商的黑体/宋体/楷体时，可将合法授权 TTF/OTF 文件只读挂载到容器，用上述变量指定绝对路径。不内置或下载未经授权的商业字体。缺少字体会报错，不会悄悄替换为无法显示中文的西文字体。

## 排程规则

默认时区 **Asia/Shanghai**，由 `TZ` 决定，控制台按设备时区输入及显示日期，不依赖浏览器时区；数据库保存 UTC 时间戳。更改设备时区后应编辑并保存已有 cron 排程，使下次执行时间重新计算。请在宿主机启用 NTP 或配置 RTC 校时，容器不具备修改系统时间的权限。

| 表达式 | 行为 |
| --- | --- |
| `*/30 * * * *` | 每小时 00、30 分 |
| `0 8 * * *` | 每天 08:00 |
| `15 9 * * 1-5` | 周一至周五 09:15 |
| `0 12 1 * *` | 每月 1 日 12:00 |

采用标准五字段 cron（分、时、日、月、周；日与周同时指定时采用 cron 的 OR 语义），不支持秒字段或 `@hourly` 等别名。单次时间必须位于未来且秒为零。后台每秒检查到期任务，将任务与后续执行时间在同一数据库事务中保存，防止重复入队。

- 同一时间多个排程按队列依次显示，物理完成时间受刷新耗时影响，不保证整分钟瞬间完成。
- 容器重启：保留未开始的手动/定时刷新；刷新途中中断的任务标记失败，不自动重复刷，屏幕状态待确认。
- 停机/休眠期间的排程最多容忍两分钟延迟；超时记录为失败并跳过，循环排程计算下一个未来时间，不集中补播历史画面。
- 最多 20 个等待/进行中的任务；手动刷新只在队列空闲时接收；队列满时定时任务记录失败并跳过本次。
- 删除或停用排程只影响后续触发，已入队的任务继续执行。
- 被排程引用的内容（包含停用/已完成排程）或正在等待/刷新的内容不能删除，返回明确提示。批量删除中任一内容不满足删除条件时，整批保留，不会部分删除。删除当前内容不会清除物理屏幕，最后成功下发图单独保留。
- 必须单实例、单 Uvicorn worker；数据目录带进程锁。多副本部署不受支持。

## 数据与运维

`./data` 挂载为 `/data`，包含 SQLite 数据库、内容 PNG、最后成功下发图与实例锁。拉取和更新镜像不会清除这些数据。预览不落盘，图片保存的是屏幕分辨率的六色图，不保留原始上传文件，文本保留结构化文档。单份内容是不可变快照；需要修改时新建一份。

更新镜像：

```bash
git pull --ff-only
docker compose pull
docker compose up -d
```

保留已有 `.env` 和 `data/`，不要再次复制示例覆盖配置。修改 `IMAGE` 可切换到已发布的指定版本。

备份时先停止服务，复制整个 `data/`（包括可能存在的 SQLite WAL 文件），再启动。不要只备份运行中数据库的单个文件。

```bash
docker compose stop
# 备份 data/ 到你选择的位置后：
docker compose start
```

常用配置：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `IMAGE` | `ghcr.io/lonespectator/rpi-zero-eink-e6-controller:latest` | Compose 使用的镜像，可固定版本 |
| `DISPLAY_DRIVER` | `waveshare` | 部署配置使用真机驱动；本地调试可设为 `mock` |

| `TZ` | `Asia/Shanghai` | IANA 时区 |

| `INA219_CURRENT_POLARITY` | `-1` | 原始电流到电量模型的方向修正，支持 `-1` / `1`；改变后重新学习电池参数 |
| `EPD_BUSY_TIMEOUT` | `180` | 单阶段 BUSY 超时秒数，总硬件操作另有 240 秒上限 |

## 开发和测试

开发使用 Python 3.12；本地开发需安装上述五种中文字体（Debian/Ubuntu：`fonts-wqy-zenhei fonts-arphic-uming fonts-arphic-ukai fonts-noto-cjk`）。Docker 镜像已包含它们。

模拟模式仅用于调试排程、内容管理和接口逻辑，不验证 GPIO/SPI 接线、实际刷屏或 INA219 读数；生产部署使用上面的真机配置。以下命令用于本地软件回归检查。

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
DATA_DIR=./data DISPLAY_DRIVER=mock BING_DEFAULT_WALLPAPER=false .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
# 另一终端：
```
